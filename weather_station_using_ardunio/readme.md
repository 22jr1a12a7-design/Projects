# 🌦️ Weather Station Using Arduino

A cost-effective and user-friendly **Arduino-based Weather Station** designed to monitor real-time environmental conditions such as **temperature, humidity, and atmospheric pressure**. This project demonstrates the application of embedded systems and IoT concepts for practical weather monitoring.

---

## 📌 Project Overview

Weather monitoring plays a crucial role in agriculture, disaster management, environmental research, and urban planning. Traditional systems are often expensive and complex.  
This project provides a **low-cost, compact, and efficient alternative** using Arduino and readily available sensors.

The system collects weather data in real time, processes it using an Arduino microcontroller, and displays the results on an LCD. It can also transmit data to the **IoT Cloud** for remote monitoring.

---

## 🎯 Objectives

- Design a compact and affordable weather monitoring system  
- Measure temperature, humidity, and atmospheric pressure  
- Display real-time sensor data on an LCD  
- Enable wireless data transmission  
- Support IoT-based monitoring and visualization  
- Serve as an educational project for Arduino and sensor integration  

---

## 🛠️ Hardware Components

- Arduino Nano / Arduino Uno  
- DHT11 Temperature & Humidity Sensor  
- BMP280 Pressure Sensor  
- 16×2 LCD Display  
- Breadboard  
- Jumper Wires  
- 5V Power Supply / Battery  
- ESP8266 Wi-Fi Module (optional for IoT)

---

## 💻 Software Requirements

- Arduino IDE  
- DHT Sensor Library  
- LiquidCrystal Library  
- Arduino IoT Cloud (optional)

---

## ⚙️ Working Principle

1. **Data Collection**  
   - DHT11 measures temperature and humidity  
   - BMP280 measures atmospheric pressure  

2. **Data Processing**  
   - Arduino reads and processes sensor data  

3. **Data Display**  
   - Real-time values are displayed on a 16×2 LCD  

4. **IoT Cloud Monitoring (Optional)**  
   - Data is sent to Arduino IoT Cloud using Wi-Fi  
   - Values can be monitored via web or mobile dashboard
